# Duality Companion

A character sheet and GM table for a private Daggerheart™ Compatible home game: guided character creation, the full sheet with the rules math done, domain cards, gear, level-ups, the Duality Dice, and a GM table with Fear, adversaries and countdowns.

Unofficial fan work, not affiliated with, endorsed, or sponsored by Critical Role or Darrington Press. Game content from the Daggerheart System Reference Document 2.0 under the Darrington Press Community Gaming License: see [ATTRIBUTION.md](ATTRIBUTION.md).
