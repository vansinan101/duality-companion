## How this project uses the licence (read before publishing)

Checked against **DPCGL 2.0** (darringtonpress.com/license, file dated 26 Aug 2026) and **SRD 2.0** (25 Aug 2026). This is a reading of the text, not legal advice.

| Question | What the licence says | What the app does |
| --- | --- | --- |
| Home game | §1.8: private, non-commercial play among friends or gaming groups, in person or online, isn't "public" and isn't Shared. | Table-password site for one group: fine. |
| Public website or app | §1.9 Permitted Formats list print and digital print works, streams, podcasts and **approved VTTs**; websites and apps aren't listed. | **Needs written permission from Darrington Press before going public.** |
| Which SRD | Public Game Content clause: SRD 2.0 is Public Game Content; SRD 1.0 remains so for existing and legacy work. | All game data is from SRD 2.0. |
| Name and branding | Name Marks (Daggerheart, Daggerheart: Hope & Fear…) can't be in a title or on the cover, and need "Compatible" beside them in descriptive text. Logos and trade dress are Prohibited Content. | Name has no marks; footer says "Daggerheart™ Compatible"; no official logos or art. |
| Endorsement | Must not state or imply endorsement or association. | "Unofficial… not affiliated" line in the footer and the credits. |
| Campaign frames | §1.9.3: frames may not be adapted into other works without separate written permission. | The Witherwild Wither-token tracker is a table switch, off by default; leave it out of any public build or ask permission. |
| Community Content logo | §4.2(f)(i): on the "front cover". | Placeholder only: download the Daggerheart (alchemy bottle) community logo from darringtonpress.com/license and add it to the sign-in screen and credits before publishing. |

### Before any public release
1. Ask Darrington Press (darringtonpress.com/contact-us) for written permission to publish a web app, describing it.
2. Add the community-content logo (step above).
3. Re-check the game text against the official SRD 2.0 PDF. The app's data came from a community Markdown transcription (github.com/ero-gfld/daggerheart-obsidian-srd-2.0) and was cross-checked number by number (3,268 values) against a second, independent transcription; open questions are listed in `DATA-NOTES.md`.
4. Remove or get permission for the Witherwild tracker.
5. Re-read the licence: it changes (four versions between May 2025 and August 2026).
